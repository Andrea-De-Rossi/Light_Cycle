# Tron Light Bikes Game

A Tron Light Bikes game inspired by Tron Legacy with local and online multiplayer capabilities.

## Features

- Local 2-player mode
- Single-player mode with AI opponents
- Dynamic responsive canvas that adapts to screen size
- Split map with void and connecting ramps
- Sprint ability for tactical gameplay
- Neon visual effects

## How to Play

### Local Setup

1. Simply open `index.html` in your browser to play local modes.

## Game Controls

- **Player 1**: Arrow keys for movement, Spacebar for sprint
- **Player 2**: WASD keys for movement, Spacebar for sprint
- **Sprint**: 1.5 seconds duration with 5 seconds cooldown

## Customization

You can customize various aspects of the game by editing:

- Game dimensions and grid size in `game.js`
- Map layout and void configuration in `game.js`
- Visual styles in `styles.css`
